# SpectraLab — Справочник по интерфейсу

## 1. Введение

**SpectraLab** — это веб-редактор и просмотрщик графики ZX Spectrum. Поддерживает множество графических форматов ZX Spectrum для просмотра, редактирования, конвертации и импорта внешних изображений с продвинутыми алгоритмами дизеринга.

- **Версия:** 1.59.3
- **Лицензия:** MIT
- **Браузер:** любой современный (Chrome, Firefox, Edge, Safari)
- **Установка не требуется** — работает полностью в браузере

![Главное окно приложения](screenshots/main_window.png)

## 2. Компоновка интерфейса

SpectraLab использует двухпанельную компоновку:

- **Левая боковая панель** (225px) — все элементы управления, разделённые по вкладкам
- **Основная область холста** — отображение и редактирование изображения

Дополнительные плавающие панели появляются по мере необходимости:

- **Preview** — миниатюрный предпросмотр (в правом нижнем углу)
- **Sprite Editor** — плавающий пиксельный редактор спрайтов
- **Memory Viewer** — просмотр памяти снапшотов как 1-битная графика
- **Floating Palette** — палитра инструментов/цветов в полноэкранном режиме (клавиша Tab)

### Панель вкладок картинок

При открытии нескольких картинок над холстом появляется панель вкладок. Каждая вкладка показывает имя файла. Точка-индикатор отмечает изменённые (несохранённые) картинки. Нажмите на вкладку для переключения; нажмите кнопку закрытия (×) для закрытия картинки.

## 5. Вкладка View

Вкладка View управляет отображением изображения.

### Масштаб (Zoom)

Выберите масштаб из выпадающего списка: **x1, x2, x3, x4, x5, x6, x8, x10, x20**. Также доступны дробные масштабы: **x1/8, x1/4, x1/2**. Можно использовать **Ctrl+колесо мыши** для масштабирования (работает в любой точке панели холста) или клавиши **1-5** для быстрого масштабирования. Ctrl+колесо мыши над левой боковой панелью выполняет стандартное масштабирование браузера.

### View Settings (раскрываемая секция)

Нажмите заголовок «View Settings» для раскрытия/сворачивания.

#### Паттерн 53c (отображается только для форматов `.53c` / `.atr`)
Появляется в верхней части View Settings при загрузке картинки 53c/atr:
- **Pattern:** выбор паттерна заливки — **Checker**, **Stripes** или **Pattern** (DD/77)
- **Blend colors** — при включении каждое знакоместо отображается как сплошной усреднённый цвет вместо паттерна дизеринга

#### Border (бордюр)
- **Цвет:** Black, Blue, Red, Magenta, Green, Cyan, Yellow, White
- **Размер:** None, Small (16px), Medium (32px)

#### Palette (палитра)
Выберите палитру отображения из выпадающего списка.

Нажмите кнопку 📂 рядом с выпадающим списком, чтобы загрузить пользовательскую палитру из текстового файла (`.txt`, `.pal`, `.csv`). Файл должен содержать 15 или 16 строк, по одному цвету на строку (индексы 0-7 = обычные, 8-15 = яркие). Если указано 15 цветов, чёрный (#000000) автоматически добавляется как индекс 0. Каждая строка может быть в формате `#RRGGBB` (hex), `RRGGBB` (hex без `#`), `#AARRGGBB` или `AARRGGBB` (альфа-канал игнорируется), или три десятичных значения `R G B` (0-255), разделённые пробелами или запятыми. Строки, начинающиеся с `;` или `//`, и пустые строки считаются комментариями. Загруженная палитра отображается как «Custom (loaded)» в выпадающем списке. Она не сохраняется — при перезагрузке страницы восстанавливается палитра по умолчанию.

#### Переключатели
- **Flash** — вкл./выкл. анимации мерцания (также клавиша **F**)
- **Attrs** — показать/скрыть наложение атрибутов. При выключенных атрибутах bitmap отображается как чёрный ink на белом paper (биты 1 = чёрный, биты 0 = белый)
- **Preview** — показать/скрыть панель предпросмотра (также клавиша **~**)

#### Paper grid (сетка)
- **Основная сетка:** None, 8px, 16px, 24px, 32px
- **Подсетка:** None, 1px, 2px, 4px, 8px, 16px

#### Border grid (сетка бордюра)
- **Сетка бордюра:** None, 8px, 16px, 24px, 32px
- **Подсетка бордюра:** None, 1px, 2px, 4px, 8px, 16px

#### Grid color (цвет сетки)
Выберите цвет сетки из списка: **Default**, **White**, **Gray**, **Black**, **Orange**, **Red**, **Green**. Удобно для улучшения видимости сетки на тёмных или светлых работах.

### Элементы управления для конкретных форматов

#### RGB3
Для формата `.3` (триколор) — выбор режима отображения:
- **Blend dark** — имитация воспринимаемой яркости на реальном ЭЛТ с учётом гашения обратного хода луча
- **Blend** — полная яркость, прямое отображение каналов R/G/B (каждая плоскость управляет своим каналом на полной интенсивности палитры)
- **Emulate flicker** — чередование кадров для имитации реального оборудования

#### Gigascreen
Для форматов `.img` (Gigascreen), `.hlr` (High Lores) и `.stl` (Stellar) — выбор режима отображения:
- **Blend dark** — имитация воспринимаемой яркости на реальном ЭЛТ с учётом гашения обратного хода луча
- **Blend** — смешанный вид обоих кадров на полной яркости
- **Emulate flicker** — чередование кадров для имитации реального оборудования

#### Font (шрифт)
Для формата SPECSCII: нажмите **Browse** для загрузки файла шрифта (`.bin`, `.SpecCHR`). По умолчанию используется ROM-шрифт ZX Spectrum.

### Reference Image — справочное изображение (раскрываемая секция)

Загрузка внешнего изображения в качестве образца для рисования за холстом.

- **Load** — выбрать файл изображения
- **Clear** — удалить справочное изображение
- **Show** — переключить видимость
- **Opacity** — прозрачность (5%–80%)
- **X / Y** — смещение позиции (может быть отрицательным)
- **W / H** — пользовательские размеры (пусто = автоподгонка)

Справочные изображения сохраняются в файлах рабочего пространства.

### Display Filters (фильтры отображения, раскрываемая секция)

Нажмите заголовок «Display Filters» для раскрытия. Установите флажок **On** для включения эффектов постобработки.

| Фильтр | Описание |
|--------|----------|
| Scanlines | Гауссов профиль луча, имитация строчной развёртки ЭЛТ |
| Noise | Статический шум плёнки с опциональной анимацией |
| Composite | Размытие цвета, имитация композитного видеосигнала |
| Phosphor Glow | Свечение люминофора |
| Vignette | Затемнение по краям экрана |
| CRT Curvature | Бочкообразное искажение, имитация кривизны ЭЛТ |
| Pixel Smoothing | Билинейная интерполяция для сглаживания пикселей |

**Пресеты:** None, CRT TV, Composite, VHS, Arcade

Настройки сохраняются в localStorage и файлах workspace (.slw).

### File Info — информация о файле (раскрываемая секция)

Отображает информацию о загруженном файле:
- **Name** — имя файла
- **Size** — размер файла в байтах
- **Format** — определённый формат
- **Dimensions** — размеры в пикселях
- **Colors used** — количество различных цветов в картинке. Для атрибутных форматов (SCR, IFL, MLT, BMC4, GMX и др.): считает уникальные значения байтов атрибутов (каждая комбинация ink+paper+bright+flash). Для NXI/SL2 и LoRes: считает уникальные индексы палитры. Обновляется в реальном времени при редактировании.
- **Hidden cells** — количество ячеек, где ink равен paper, но bitmap не весь 0x00 и не весь 0xFF, что указывает на невидимые пиксельные данные. Показывается для форматов с редактируемым bitmap. Не показывается для атрибутных форматов с фиксированным bitmap (GMX 160, HLR, 53c, STL). Обновляется в реальном времени при редактировании.
- **Frames** — количество кадров (для SCA-анимаций)
- **Type** — тип данных (для SCA)
- **Delay** — задержка кадра (для SCA)

## 7. Вкладка Edit — Цвет и палитра

### Стандартная палитра

Палитра показывает 8 цветов ZX Spectrum (0-7). Нажмите для выбора ink (помечается **I**), правый клик для выбора paper (помечается **P**).

Под палитрой:
- **Bright (B)** — переключение атрибута яркости
- **Flash (F)** — переключение атрибута мерцания
- Клавиша **X** — поменять ink и paper местами

### Палитра ULA+

Отображается при редактировании картинок формата ULA+. 64 цвета в 4 CLUT (Color Look-Up Table), по 16 цветов в каждом.

- **Grid** режим — все 64 цвета в сетке 8×8
- **Classic** режим — одна CLUT с кнопками выбора (0, 1, 2, 3)
  - CLUT 0: FLASH=0 BRIGHT=0
  - CLUT 1: FLASH=0 BRIGHT=1
  - CLUT 2: FLASH=1 BRIGHT=0
  - CLUT 3: FLASH=1 BRIGHT=1
- **Переключатель** — смена между Grid и Classic режимами
- **Сохранение палитры** — экспорт 64-байтного `.pal`-файла (кодировка GRB332)
- **Загрузка палитры** — импорт `.pal`-файла
- **Ctrl+клик** на цвете — открытие редактора цвета (R/G/B слайдеры, формат GRB332: 3 бита зелёного, 3 бита красного, 2 бита синего)
- **Shift+клик** на цвете — пометить как источник для копирования (анимированная рамка), затем:
  - **Клик** на другом цвете — скопировать GRB-значение источника в цель
  - **Shift+клик** на другом цвете — поменять оба GRB-значения местами
  - **Клик на том же цвете** или **Escape** — отмена

Ink и paper должны быть из одного CLUT.

### Режим ULANext

Отображается при просмотре/редактировании картинок формата ULANext (расширенная палитра ZX Spectrum Next). ULANext использует настраиваемую маску ink для разделения каждого байта атрибутов между индексами ink и paper, позволяя использовать до 256 цветов ink или 256 цветов paper.

- **Автоопределение** по размеру файла (6945–7426 байт) и валидации маски ink
- **Маска ink** — определяет разделение ink/paper (8 допустимых значений: $01–$FF)
- **Палитра** — записи 8-бит (1-байтный RRRGGGBB) или 9-бит (2-байтный RGB333), определяется автоматически
- **Flash отключён** — биты 6-7 атрибутов используются для индексации палитры
- **Информация о формате** — показывает значение маски, количество цветов ink/paper и разрядность палитры
- Цвета отображаются автоматически; стандартные инструменты рисования работают с битмапом и атрибутами

### Палитра Next (NXI / SL2 / LoRes)

Отображается при редактировании форматов ZX Next с индексированными цветами (NXI, SL2, LoRes, LoRes Radastan). 256 цветов (или 16 для 4bpp-режимов) в сетке из 16 столбцов.

- **Левый клик** — выбор ink
- **Правый клик** — выбор paper
- **Ctrl+клик** на цвете — открытие редактора цвета (R/G/B слайдеры, формат RGB333: 3 бита красного, 3 бита зелёного, 3 бита синего)
- **Shift+клик** на цвете — пометить как источник для копирования (анимированная рамка), затем:
  - **Клик** на другом цвете — скопировать RGB-значение источника в цель
  - **Shift+клик** на другом цвете — поменять оба RGB-значения местами и перенаправить пиксели
  - **Клик на том же цвете** или **Escape** — отмена
- **Сортировка** — None, Luminance, Hue, RGB; опция Reverse
- **Sort by usage** — физически переупорядочивает записи палитры: используемые цвета перемещаются в начало (по убыванию частоты использования пикселей), неиспользуемые — в конец. Индексы пикселей перенаправляются, изображение остаётся неизменным. Отменяется через Ctrl+Z.
- **Сохранение палитры** — экспорт файла палитры
- **Загрузка палитры** — импорт файла палитры

**Палитра и сохранение:** Файлы NXI содержат палитру в заголовке файла — изменения палитры всегда сохраняются. Файлы SL2 с нестандартной палитрой автоматически сохраняют палитру после пиксельных данных (файл увеличивается: 49664, 82432 или 81952 байт); файлы со стандартной палитрой RGB332 сохраняются как только пиксельные данные. Форматы LoRes (SLR) и Radastan (RAD без встроенной палитры) не хранят палитру в файле. При редактировании палитры в этих форматах при сохранении появится предупреждение, что пользовательские цвета будут потеряны при повторной загрузке (будет использована палитра по умолчанию). Файлы Radastan, загруженные со встроенной палитрой (6160 байт GRB332 или 6176 байт RGB333), сохраняют палитру при записи.

### Палитра Gigascreen

Отображается для форматов Gigascreen, HLR и STL. Сетка из 16 столбцов показывает все виртуальные цвета, создаваемые чередованием двух кадров.

- Левый клик = выбор ink
- Правый клик = выбор paper
- Секция **Cell Colors** показывает 4 доступных цвета для текущей ячейки
  - **L** = цвет левой кнопки мыши
  - **R** = цвет правой кнопки мыши

### Палитра 53c/127c

Отображается при редактировании формата 53c/atr. Сетка уникальных цветовых образцов, представляющих все комбинации ink/paper через выбранный паттерн.

- Нажмите на образец для выбора цветовой комбинации
- **Сортировка:** Hue (по умолчанию), RGB или Color (по байту атрибута)
- **Reverse** — переворачивает порядок сортировки
- Адаптируется к текущему паттерну: Checker (~53 цвета), DD77 (~127 цветов)
- Выбранный цвет сохраняется при смене сортировки или паттерна

### Палитра RGB3

Отображается для формата RGB3 (.3). 8-цветная палитра с выбором левым/правым кликом (без отдельных ink/paper). Цвета палитры зависят от режима отображения: Blend — полная яркость RGB, Blend dark — реалистичные воспринимаемые цвета (1/3 яркости на канал × CRT-фактор затемнения), Flicker — чередование кадров.

## 14. Вкладка Edit — Редактор SPECSCII

Для картинок формата SPECSCII появляется палитра символов (сворачиваемая):

- **Сетка символов** — ROM-шрифт (0x20-0x7F) и блочная графика (0x80-0x8F)
- Клик на тайле для выбора символа для рисования
- **Сортировка по весу** (кнопка Sort) — переключает между порядком Code (последовательный) и Weight (сортировка по количеству пикселей, от лёгких к тяжёлым; по умолчанию). Блочная графика отображается в виде симметричной сетки 5×3 в режиме Weight. Настройка сохраняется в localStorage
- **Предпросмотр символа** — увеличенное отображение выбранного символа с его кодом
- Правый клик на холсте для захвата символа + атрибутов с экрана

Доступные инструменты в режиме SPECSCII: Pixel, Line, Rectangle, Circle, Flood Fill, Eraser, Text.

Режимы рисования: Set (размещение символа), Invert (обмен ink/paper), Recolor (только атрибуты). Eraser очищает ячейку и удаляет её из текущего слоя.

SPECSCII поддерживает OVER-слои (XOR-композитинг), загружаемые из управляющих кодов потока. Экспорт SPECSCII в `.scr` через вкладку Transform.

## 15. Вкладка Transform (Xform)

### Workspace (рабочее пространство)

- **Save Workspace** — сохранить все открытые картинки и спрайты в `.slw`-файл
- **Load Workspace** — загрузить файл рабочего пространства (`.slw`)

Кнопки Workspace всегда доступны, даже без загруженной картинки. Остальные инструменты трансформации требуют загрузки или создания картинки.

### Сохранить все картинки (Save all pictures)

Группа видна только когда **открыто две или более картинок**. Все четыре варианта используют базовое имя файла `spectralab_pictures` (с расширением `.zip` / `.gif` / `.sca`).

- **ZIP (originals)** — упаковывает все открытые картинки в их родном бинарном формате в один `.zip`. Каждый файл сохраняет своё исходное расширение (например, `.scr`, `.bsc`, `.ifl`, `.img`); дублирующиеся имена различаются суффиксами ` (2)`, ` (3)`, …
- **ZIP (PNG / GIF)** — упаковывает все картинки, отрендеренные с текущими настройками вида (масштаб, бордюр, палитра, фильтры дисплея), в виде PNG. Картинки с мерцающими атрибутами сохраняются как двухкадровые анимированные GIF на стандартной частоте FLASH.
- **Animated GIF** — собирает все картинки в один анимированный GIF, 500 мс на кадр. Картинки с мерцанием дают два кадра (обычная фаза + инвертированная). Требуется, чтобы все картинки рендерились в один и тот же размер холста — при смешении форматов с разными размерами экспорт прерывается с ошибкой.
- **SCA** — собирает все картинки в один SCA-файл анимации, 500 мс на кадр. Требуется, чтобы все картинки были в обычном формате SCR (256×192, 6912 байт); цвет бордюра берётся из текущей настройки. При наличии любой картинки в другом формате экспорт прерывается со списком несовместимых файлов.

Активная картинка сохраняется — операция кратковременно перебирает все открытые картинки для рендера и затем возвращается на исходную вкладку.

### History (история)

- **Undo** (Ctrl+Z) — отмена действия (до 32 уровней)
- **Redo** (Ctrl+Y) — повтор отменённого действия
- **Clear** — очистка всего экрана

### Конвертация формата

Выпадающий список **Convert to...** для конвертации текущей картинки в другой формат.

Доступные конвертации:
- **Без потерь**: SCR ↔ ATTR, SCR ↔ BSC ↔ BSP, SCR ↔ ULA+, NXI ↔ SL2 (все режимы: 256×192, 320×256, 640×256). При конвертации NXI → SL2 с нестандартной палитрой появляется диалог: сохранить палитру (встроить в SL2), квантовать к стандартной RGB332 (с потерями) или убрать палитру (оставить индексы без изменений)
- **С потерями (рендер + квантизация)**: SCR/ULA+ → NXI 320×256/640×256, NXI/SL2 между режимами (256↔320↔640), NXI/SL2 → SCR
- **Символьное сопоставление**: SCR → SPECSCII — сопоставляет битовый паттерн каждой ячейки 8×8 с наиболее подходящим символом ROM-шрифта или блочной графикой, сохраняя яркость и мерцание; проверяет как прямое, так и инвертированное (обмен ink/paper) сопоставление; скрытые пиксели (ink == paper) сопоставляются с наиболее подходящим глифом, чтобы битовый паттерн сохранялся для редактирования

### Экспорт

- Выпадающий список формата экспорта (доступные варианты зависят от загруженного формата)
- Флажок **Embed** — встраивание данных как DB-строк в ASM-файл (выключен = использовать INCBIN-ссылки)
- Кнопка **Export** — экспорт в выбранный формат
- Кнопка **PNG/GIF** — экспорт текущего экрана в PNG или анимированный GIF
  - Использует все текущие настройки вкладки View: зум, размер/цвет бордюра, сетка/подсетка, палитра, фильтры
  - Для форматов семейства gigascreen (Gigascreen, MGH, HLR, STL, BSP-gigascreen, chr$-gigascreen): диалог выбора **Blended** (усреднённые цвета → PNG) или **Flicker** (два чередующихся кадра → анимированный GIF ~50fps)
  - Для картинок с атрибутами flash: диалог выбора **Animated GIF** (двухкадровая анимация мерцания, 320мс на фазу) или **Static PNG** (только нормальная фаза)
  - Для остальных форматов: экспорт напрямую в PNG

### Экспорт в RCS

Для формата **SCR** в выпадающем списке Export доступен вариант `.rcs (RCS reordered)` — экспорт экрана в формате [RCS (Re-ordered Compressed Screen)](https://github.com/einar-saukas/RCS) от Einar Saukas. 6144 байта битмапа переупорядочиваются по схеме S→C→R→L (сектор → столбец → символьная строка → пиксельная линия), группируя пространственно связанные байты вместе для значительно лучшего сжатия упаковщиками типа ZX7. 768 байт атрибутов добавляются без изменений. Выход: 6912-байтный файл `.rcs`.

RCS-файлы также можно открывать напрямую — переупорядочивание автоматически обращается при загрузке, конвертируя обратно в стандартный SCR для просмотра и редактирования.

### Сжатие ZX7 / ZX0

Для формата **SCR** в выпадающем списке Export доступны варианты сжатия [ZX7](https://spectrumcomputing.co.uk/entry/27996/ZX-Spectrum/ZX7) и [ZX0](https://github.com/einar-saukas/ZX0) (формат v2) от Einar Saukas:

- **`.scr.zx7 (ZX7 compressed)`** — сжатие данных экрана алгоритмом ZX7 (прямой режим)
- **`.rcs.zx7 (RCS + ZX7)`** — сначала переупорядочивание RCS, затем сжатие ZX7
- **`.scr.zx0 (ZX0 compressed)`** — сжатие данных экрана алгоритмом ZX0 (прямой режим)
- **`.rcs.zx0 (RCS + ZX0)`** — сначала переупорядочивание RCS, затем сжатие ZX0
- **`.scr.lc (LC compressed)`** — сжатие данных экрана алгоритмом Laser Compact 5.2.1 (включает заголовок LCMP5; переупорядочивание и обработка сегментов встроены)
- **`.scr.upk (upkr level 1)`** — сжатие данных экрана алгоритмом upkr (rANS-энтропийное кодирование, настройки Z80, быстрое сжатие)
- **`.scr.upk (upkr level 9)`** — сжатие данных экрана алгоритмом upkr (rANS-энтропийное кодирование, настройки Z80, лучшее сжатие)
- **`Compare compressions...`** — открывает диалог сравнения всех двенадцати вариантов сжатия:
- **`.scr.lc (LC compressed)`** — сжатие данных экрана алгоритмом Laser Compact 5.2.1 (включает заголовок LCMP5; переупорядочивание и обработка сегментов встроены)
- **`.scr.upk (upkr level 1)`** — сжатие данных экрана алгоритмом upkr (rANS-энтропийное кодирование, настройки Z80, быстрое сжатие)
- **`.scr.upk (upkr level 9)`** — сжатие данных экрана алгоритмом upkr (rANS-энтропийное кодирование, настройки Z80, лучшее сжатие)
- **`Compare compressions...`** — открывает диалог сравнения всех двенадцати вариантов сжатия:
  - Plain SCR (6912 байт, несжатый базовый вариант)
  - ZX7 / ZX7 backwards (обратный)
  - RCS + ZX7 / RCS + ZX7 backwards (обратный)
  - ZX0 / ZX0 backwards (обратный)
  - RCS + ZX0 / RCS + ZX0 backwards (обратный)
  - LC (Laser Compact 5.2.1)
  - upkr level 1 / upkr level 9

  Диалог открывается с пустой таблицей (все размеры отображаются как «—»). Нажмите кнопку **Compare** для запуска сжатия — результаты появляются по одному, лучший вариант подсвечивается и выбирается автоматически. Диалог остаётся открытым после сохранения, что позволяет экспортировать несколько форматов без повторного запуска сжатия.

  **⚙ Настройки форматов** (иконка шестерёнки в заголовке) — открывает панель настроек для включения/отключения семейств форматов (ZX7, ZX0, варианты RCS, LC, upkr). Отключённые форматы исключаются из таблицы сравнения. Для upkr можно выбрать вариант распаковщика: Compact (130 байт код + 320 байт массив вероятностей = 450 байт) или Fast (155 байт код + 320 байт массив вероятностей = 475 байт, развёрнутый цикл умножения). Все настройки сохраняются в localStorage и сохраняются между сессиями.

  Выпадающий список **Data** — выбор сжимаемой области данных:
  - **Full SCR** (по умолчанию) — полные 6912 байт (битмап + атрибуты)
  - **Bitmap only** — 6144 байта (только битмап, без атрибутов)

  Выпадающий список **Segment** (доступен только при Data = «Bitmap only») — выбор сегмента битмапа:
  - **Whole** — все 6144 байт битмапа
  - **Third 1 / 2 / 3** — отдельные трети битмапа по 2048 байт
  - **Thirds 1+2 / 2+3** — две последовательные трети (4096 байт)

  Варианты RCS отображаются только при Segment = «Whole» (RCS переупорядочивает весь 6144-байтный битмап; разрезание после переупорядочивания бессмысленно). Для отдельных сегментов отображаются только plain + ZX7/ZX0 прямой/обратный.

  **Clean hidden cells** — при включённом чекбоксе скрытые ячейки (ink === paper с нетривиальным битмапом) очищаются на временной рабочей копии перед сжатием, используя плотность битмапа соседних ячеек для выбора значения заливки. Исходное изображение не изменяется.

  **Optimize attributes** — при включённом чекбоксе ink/paper меняются местами, а битмап инвертируется в ячейках, где установленных битов больше, чем сброшенных (режим «minimize ink bits»), на той же временной копии. Обе оптимизации можно комбинировать; переключение любого чекбокса сбрасывает таблицу в «—» (устаревшие результаты).

  Изменение любой опции (Data, Segment, чекбоксы) сбрасывает таблицу — нажмите Compare для повторного запуска.

  Столбец **Depacker** — показывает размер Z80-распаковщика в байтах для каждого метода, включая код и необходимый буфер: ZX7 прямой/обратный = 69 байт, ZX0 прямой = 68, ZX0 обратный = 69. Варианты RCS используют [«умные» интегрированные декодеры](https://github.com/einar-saukas/RCS), распаковывающие и декодирующие напрямую в экран без временного буфера: RCS+ZX7 = 110, RCS+ZX7 обратный = 110, RCS+ZX0 = 112, RCS+ZX0 обратный = 113. ### Optimize Attributes (оптимизация атрибутов)

Доступно только для формата **SCR**. Автоматически меняет местами ink↔paper и инвертирует биты битмапа в ячейках 8×8, где текущее назначение неоптимально. Отображаемые цвета остаются идентичными — меняется только полярность битмапа и роли ink/paper. Ячейки с ink == paper или flash пропускаются.

Четыре режима:

| Режим | Правило | Применение |
|-------|---------|------------|
| Paper = lighter color | Переворот, если paper темнее ink (по яркости) | Естественный вид — paper всегда светлый фон |
| Paper = majority pixels | Переворот, если более половины пикселей — ink (установленные биты) | Уменьшение плотности ink — больше «белого» в битмапе |
| Combined | Переворот, если paper темнее, или при равной яркости ink в большинстве | Общая очистка — учитывает яркость и плотность |
| Minimize ink bits | Переворот, если установленных битов больше, чем нулевых | Лучшее сжатие — меньше единичных битов = лучший коэффициент RLE/LZ |

Информационная метка показывает количество перевёрнутых ячеек. Операция отменяема (Ctrl+Z).

### Clean Hidden Cells (очистка скрытых ячеек)

Доступно для форматов с битмапом и атрибутами: **SCR**, **BSC**, **IFL**, **MLT**, **BMC4**, **GMX**, **Gigascreen**, **ULA+**. Скрыто для форматов только с атрибутами (GMX 160, HLR, 53c, STL, SPECSCII) и форматов без атрибутов.

«Скрытая ячейка» — это ячейка, где ink равен paper, но битмап неоднороден (не весь 0x00 и не весь 0xFF). Пиксельный рисунок невидим на экране, так как оба цвета одинаковы, но он занимает байты и увеличивает размер при сжатии.

Нажмите **Apply** для очистки всех скрытых ячеек. Для каждой скрытой ячейки инструмент анализирует плотность битмапа четырёх соседних ячеек (вверх, вниз, влево, вправо):
- Если большинство битов соседних ячеек установлены → заполнение 0xFF
- Иначе → заполнение 0x00
- Если соседей нет (угол/край без валидных соседей) → заполнение 0x00

Это сохраняет визуальную непрерывность с окружающими ячейками. Информационная метка показывает количество очищенных ячеек. Операция отменяема (Ctrl+Z). Счётчик «Hidden cells» в File Info обновляется после очистки.

## 16. Вкладка Sprites

**Спрайтсет** — именованная запись в списке, содержащая один или несколько отдельных **спрайтов** (кадров анимации). Каждый спрайтсет имеет фиксированные размеры (W × H) и цветовой режим.

- **Двойной клик** — выбрать и открыть в редакторе спрайтов
- **Правый клик** — открыть контекстное меню с операциями над выбранными спрайтсетами
- **+ Add** — добавить новый спрайтсет
- **Delete** — удалить выбранные спрайтсеты
- **Clear all** — удалить все спрайтсеты (с подтверждением)

### Контекстное меню (правый клик на списке спрайтсетов)

- **Merge selected to animation** — объединить выбранные спрайтсеты (с одинаковыми размерами и режимом) в один спрайтсет с несколькими спрайтами
- **Add frames to…** — скопировать спрайты из выбранных спрайтсетов в указанный целевой спрайтсет
- **Move frames to…** — переместить спрайты в целевой спрайтсет, удалив исходные
- **Split frames to sprites** — разбить многокадровый спрайтсет на отдельные однокадровые (напр. `Name_f1`, `_f2`, …)
- **Delete selected** — удалить все выбранные спрайтсеты

### Свойства спрайтсета

При выборе спрайтсета:

- **Name** — имя спрайтсета (макс. 16 символов)
- **W / H** — размеры в знакоместах (1-8 × 1-8, каждое = 8×8 пикселей); блокируются после рисования (очистите все спрайты для разблокировки)
- **Mode** — Mono, Attributed или Multicolour (8×1 / 8×2 / 8×4 — высота ячейки атрибутов); блокируется после рисования
- **+ Add** — добавить новый пустой спрайтсет
- **Edit** — открыть плавающий редактор спрайтов
- **Delete** — удалить выбранные спрайтсеты
- **Use as Brush** — использовать спрайт как кисть на основном холсте

### Grab from Screen — захват с экрана

Захват спрайтов из загруженной картинки. Установите **W / H** и **Mode** в свойствах спрайтсета перед захватом — захват использует эти значения для размера ячеек и цветового режима.

- Кнопка **Grab** — войти в режим захвата, перетащить прямоугольник на холсте
- Кнопка **Stop** / Escape — выйти из режима захвата
- Каждый захват создаёт **новый спрайтсет** с захваченными спрайтами
- **Режим захвата:**
  - Single sprite — захват одного спрайта
  - Sprite phases — захват как спрайтов анимации
  - Singles grid — захват сетки отдельных спрайтсетов
  - Phases grid — захват сетки наборов спрайтов
- **Настройки сетки:** размер по ячейкам (используются W/H из свойств спрайтсета) или количеству, столбцы/строки, порядок (L→R,T→B или T→B,L→R)

- **Speed** — слайдер скорости анимации (1-30)

### Кнопки трансформации

- **FlipH** / **FlipV** — отражение по горизонтали/вертикали
- **RotCW** / **RotCCW** — поворот по/против часовой стрелки
- Флажок **Scroll attr** — при включении стрелки сдвига также прокручивают атрибуты; атрибуты перемещаются, когда накопленный пиксельный сдвиг достигает границы ячейки атрибутов (напр. каждые 2 пикселя для 8×2, каждый 1 пиксель для 8×1); скрыт в режиме Mono
- **← → ↑ ↓** — сдвиг спрайта на 1 пиксель (с опциональной прокруткой атрибутов)
- **Inv** — инвертировать все пиксели
- **Clr** — очистить текущий спрайт

## 18. Image Import — импорт изображений

При загрузке файла PNG, JPG, WebP, BMP или GIF открывается диалог Image Import.

Для многокадровых анимированных GIF рядом с кнопкой Import появляется **выпадающий список режимов**:
- **Picture** — импорт первого кадра как статичной картинки с выбранным форматом/дизерингом/настройками
- **Flash** (только для 2-кадровых GIF) — оба кадра конвертируются в один SCR с атрибутами FLASH. Ячейки, отличающиеся между кадрами, используют бит FLASH (0x80) для чередования ink↔paper каждые 320мс; одинаковые ячейки остаются статичными
- **Animation** — все кадры конвертируются в SCA-анимацию. Каждый кадр конвертируется в формат SCR, задержки кадров из GIF сохраняются (конвертируются в единицы SCA по 20 мс). После импорта доступен полный редактор SCA (плёнка кадров, воспроизведение, обрезка, редактирование задержек, оптимизация, экспорт)

### Компоновка

Диалог показывает два холста:
- **ORIGINAL** — исходное изображение с выбором масштаба (Fit, x1–x4). Fit масштабирует для заполнения доступного пространства, максимум x2.
- **PREVIEW** — результат дизеринга под ZX Spectrum с выбором масштаба (Fit, x1–x5, по умолчанию x2) и флажком Grid для наложения сетки атрибутов 8×8.

Оба холста показывают полосы прокрутки, когда увеличенное изображение не помещается в доступное пространство.

### Вкладка Image

#### Source (источник)

Обрезка исходного изображения:
- **X, Y, W, H** — прямоугольник обрезки
- **Reset** — сбросить к исходному размеру
- **Full** — использовать полное изображение
- **Detect** — автоопределение области 256×192
- **4:3** — зафиксировать соотношение сторон 4:3
- **LAB colors** — использовать цветовое пространство LAB для перцептуального сопоставления
- **Grayscale** — преобразовать в оттенки серого перед обработкой
- **Mono output** — вывод только чёрно-белый (ink 0, paper 7, bright). Работает со всеми форматами: SCR, IFL, MLT, BSC, BMC4, GMX, Gigascreen, HLR, STL, RGB3, ULA+, GMX 160×200, 53c, SPECSCII, NXI, SL2, LoRes, Radastan, ZXP

#### Transform (преобразование)

- **Fit mode:**
  - Stretch — растянуть до заполнения (может исказить)
  - Letterbox — вписать в цель с полосами
  - Fill/crop — заполнить цель, обрезать лишнее
  - Fit width — подогнать по ширине
  - Fit height — подогнать по высоте

- **Align:** Top-Left, Top, Top-Right, Left, Center, Right, Bottom-Left, Bottom, Bottom-Right

- **Алгоритмы дизеринга:**

  Cell-Aware (с учётом атрибутов):
  - Cell Floyd, Cell Atkinson, Cell Serpentine, Cell Sierra 2, Cell Riemersma, Cell Ordered, Cell Blue Noise, Cell Pattern, Cell None

  Global (классические):
  - Floyd-Steinberg, Jarvis, Stucki, Burkes, Sierra, Sierra Lite, Sierra 2-Row, Serpentine, Dizzy, Riemersma, Atkinson, Ordered 2×2, Ordered 4×4, Ordered 8×8, Blue Noise, a-dither, Pattern, Noise, None

  По умолчанию дизеринг — **None** (ближайший цвет, без дизеринга).

  - Ползунок **Strength** (0–100%) — регулирует, сколько ошибки квантования распространяется при диффузии ошибки. 0 = чистое квантование (без диффузии), 100 = классическая полная диффузия. Для методов ordered / pattern / blue-noise / a-dither значение Strength > 0 включает гибридный режим ordered + диффузия (упорядоченный порог используется как смещение, а остаток ошибки диффундируется ядром Флойда-Стейнберга).
  - Флажок **Serpentine scan** — чередует направление обхода строк во время диффузии ошибки (слева направо по чётным строкам, справа налево по нечётным), уменьшая горизонтальные полосы. Применяется ко всем глобальным методам с диффузией ошибки.
  - **Dizzy** (Liam Appelbe, 2023) — диффузия ошибки с динамическим знаменателем: для каждого пикселя суммируются веса необработанных соседей в пределах изображения (ортогональные = 1.0, диагональные = 0.1), и `error × weight / denom` распределяется пропорционально. Ошибка не теряется на краях; получаются паттерны, близкие к голубому шуму.
  - **a-dither** (арифметический дизеринг, формула FFmpeg `((x + y·236) · 119) & 0xff`) — хеш-порог на пиксель. Пространственно стабильный, близкий к голубому шуму, без таблиц поиска.

- **Dither Regions** (вкладка **Dither**) — рисование лассо-регионов на исходном или превью-холсте для назначения разных алгоритмов дизеринга и силы дизеринга разным областям. До 3 цветных регионов (красный, зелёный, синий), каждый со своим выпадающим списком метода дизеринга и **ползунком силы** (0–100%). Последние использованные методы и силы сохраняются в localStorage (по умолчанию: Floyd-Steinberg, Ordered 2×2, Riemersma; все 100%). Управление:
  - **Радиокнопки регионов** (1/2/3) — выбор региона для рисования. Каждый имеет цветовую метку, список метода и ползунок силы.
  - **Ползунок силы** (0–100) — управляет интенсивностью дизеринга для региона независимо от основного ползунка Strength.
  - **Erase** — режим стирания: удаляет пиксели региона (возврат к дизерингу по умолчанию).
  - **Show** — видимость оверлея: Source, Preview, Both или None. Переключение этого списка только перерисовывает оверлей без повторной конвертации.
  - **Clear All** — удаление всех регионов и сброс маски.
  - **Рисование лассо:** переключитесь на вкладку **Dither**, затем кликайте на исходном или превью-холсте для размещения вершин полигона. Двойной клик или клик рядом с первой вершиной закрывает полигон. Правый клик или **Escape** отменяет текущий полигон. Вкладка **Image** — для управления кропом; вкладка **Adjustments** — для настройки цвета/уровней; вкладка **Dither** — для рисования лассо.
  - При конвертации каждая ячейка (для ячеечных форматов) или пиксель (для попиксельных форматов) использует метод и силу дизеринга своего региона; неназначенные области используют основной выпадающий список Dither и глобальный ползунок Strength. Если несколько регионов перекрывают одну ячейку, побеждает регион с наибольшим количеством пикселей в этой ячейке. Одинаковый метод с разной силой создаёт отдельные проходы конвертации.
  - **Производительность:** при перетаскивании любого ползунка настройки многопроходная композиция регионов пропускается для отзывчивости превью. Полнокачественный рендер со всеми регионами выполняется при отпускании ползунка.
  - Поддерживаемые форматы: SCR, IFL, MLT, BSC, BMC4, RGB3, Gigascreen/MG, GMX 640, ULA+, MLT+ULA+, ZXP ULA+, NXI (256, 320, 640), SL2 (256, 320, 640), LoRes, LoRes RAD.
  - Маска сбрасывается при смене формата или загрузке нового изображения.

- **Paper** — правило назначения цветов ink и paper в каждой ячейке (не применяется к формату ULA+, который использует независимые половины CLUT):
  - **Darker color** — по умолчанию; более тёмный из двух цветов ячейки становится paper (для каждой ячейки отдельно, по перцептуальной яркости). Для одноцветных ячеек (ink и paper одинаковые) цвет сравнивается с серединой: тёмные цвета становятся paper (биты 0), светлые — ink (биты 1)
  - **Lighter color** — более светлый из двух цветов ячейки становится paper. Для одноцветных ячеек цвет сравнивается с серединой: светлые цвета становятся paper (биты 0), тёмные — ink (биты 1)
  - **First pixel paper** — цвет левого верхнего пикселя в каждой ячейке становится paper; полезно для спрайтшитов, где угловой пиксель рамки определяет цвет фона

#### Output (выход)

- **Format:** SCR, ULA+, 53c (attr), IFL (8×2), BMC4 (8×4), MLT (8×1), MLT+ULA+, BSC, BSP, RGB3, Gigascreen, HLR, STL, GMX 640×200, GMX 160×200, NXI (256×192, 320×256, 640×256), SL2 (256×192, 320×256, 640×256), SPECSCII, Mono, Mono 2/3, Mono 1/3, LoRes, Radastan, ZXP, chr$, btile (Nirvana 16×16), wtile (Nirvana 24×16)
- Выбор **Palette**
- **53c Pattern** (для формата 53c): Checker, Stripes, DD/77
- **SPECSCII Charset** (для формата SPECSCII): Full (ROM-шрифт + блочная графика, 112 глифов), ASCII (только ROM-шрифт, 96 глифов), UDG (только блочная графика, 16 глифов + пробел)
- **ULA+ Palette:** Auto, Load .pal, From picture
- **Position:** X, Y смещение
- **Size:** W, H (с фиксацией соотношения сторон). Для btile/wtile значения привязываются к кратным размеру тайла при Enter/blur (16px для btile, 24px ширина / 16px высота для wtile)
- **Tile to screens** — разбить обрезанный источник на сетку картинок:
  - Каждый тайл — один полный выходной формат (например 256×192 для SCR)
  - Размер сетки рассчитывается автоматически (столбцы × строки = всего картинок)
  - Крайние тайлы дополняются чёрным
  - Имена файлов: `filename_col_row.ext`
  - Жёлтая пунктирная сетка на холсте оригинала показывает границы тайлов
  - Кнопки ◄/► переключают между тайлами; предпросмотр показывает реальный результат конвертации каждого тайла
  - Элементы Position/Size/Fit/Align отключаются при включённом тайлинге

### Вкладка Adjustments (настройки)

## 22. Полноэкранный режим

Нажмите **F11** для переключения полноэкранного режима из любой вкладки — просмотрщика или редактора.

- **Просмотр (Viewer)** — показывает только холст с активными фильтрами дисплея; без боковой панели и плавающей палитры

Плавающая палитра включает все инструменты рисования, инструменты выделения/буфера обмена, цветовую палитру и переключатель Bright. Она отображается только при входе в полноэкранный режим из вкладки Edit.

## 24. Редактор шрифтов (Font Editor)

Редактор шрифтов — отдельная страница (`font_editor.html`) для создания и редактирования растровых шрифтов ZX Spectrum. Поддерживает фиксированные шрифты 8×8 и пропорциональные шрифты FZX. Открывается по ссылке **Font** в нижней панели вкладки View, или напрямую через `font_editor.html`.

### Элементы управления в заголовке

- **Load** — открыть файл шрифта (`.768`, `.ch8`, `.bin`, `.SpecCHR`, `.fnt`, `.fzx`)
- **Save** — контекстное сохранение. Действие зависит от текущего количества глифов: 96 глифов сохраняет `.768` напрямую; 21 глиф — `.udg`; 256 глифов — диалог Normal/Interlaced; 117 глифов (96+21) — выбор из Single file, Font+UDG или UDG+Font; >256 глифов — диалог экспорта диапазона; остальные количества сохраняют `.bin`. FZX-шрифты сохраняются как `.fzx` напрямую.
- **Append** — загрузить файл шрифта и добавить его глифы после существующих (до 1024 всего)
- **New ▾** — создать новый шрифт: 96 глифов, 256 глифов, произвольное количество (до 1024), «взорванный» (256 чересстрочных), или новый FZX-шрифт
- **?** — показать горячие клавиши и справку
- **Light / Dark** — переключение темы (синхронизируется с SpectraLab через `localStorage`)

### Сетка глифов (левая панель)

Отображает все глифы в масштабе 4× в сетке из 16 столбцов. Щёлкните по глифу для выбора. Для FZX-шрифтов сетка использует flexbox-раскладку с ячейками переменной ширины.

- Подсказка при наведении показывает индекс глифа, hex-код и привязанный символ
- При ширине, отличной от 8, неактивные столбцы затемняются
- Флажок **Grid** включает/выключает отображение сетки пикселей
- Флажок **Labels** показывает привязанный символ под каждым глифом в сетке

### Инструменты рисования

Панель инструментов над редактором содержит пять инструментов:

| Инструмент | Кнопка | Клавиша | Левая кнопка мыши | Правая кнопка мыши |
|------------|--------|---------|-------------------|-------------------|
| Пиксель | ✎ | P | Переключение (XOR) | Стирание |
| Линия | ╱ | L | Рисование линии (установка) | Стирание линии |
| Прямоугольник | ☐ | R | Контур | Заливка |
| Круг | ○ | O | Контур | Заливка |
| Ластик | ⌫ | E | Стирание от руки | Стирание прямоугольной области |

**Фигурные инструменты** (линия, прямоугольник, круг): нажмите для установки начальной точки, перетащите для предпросмотра фигуры (полупрозрачное наложение), отпустите для подтверждения. Перемещение мыши за пределы холста отменяет фигуру. Правая кнопка ластика работает аналогично — выделите область, отпустите для очистки.

**Инструменты свободного рисования** (пиксель, ластик): нажмите и перетаскивайте для непрерывного рисования. Ластик использует интерполяцию Брезенхэма для плавных штрихов без пропусков.

Все инструменты работают как в обычном (8×8), так и в FZX-режиме, с учётом активных столбцов, защиты строки 0 (режим переменной ширины) и флажка «Whole font».

### Редактор пикселей (центральная панель)

Выбранный глиф отображается в крупном масштабе (50× для 8×8, динамический размер для FZX — вписывается в ~400 пикс.). Щёлкните или перетащите курсор для рисования активным инструментом.

- **Invert** — инвертировать все биты глифа (клавиша **I**)
- **Clear** — обнулить все биты (клавиша **Delete**)
- **Whole font** — применять Invert/Clear/трансформации и редактирование пикселей ко всем глифам сразу. В режиме переменной ширины учитывается ширина каждого глифа.
- В режиме переменной ширины строка 0 (байт ширины) защищена от редактирования. Флажок **Hide W** (по умолчанию: включён) скрывает её в сетке, редакторе и текстовом превью.

### Колонка управления (справа от превью)

- **Glyphs** — количество глифов (1–1024). Работает как для фиксированных, так и для FZX-шрифтов. Изменение количества сохраняет существующие данные глифов и привязку символов.
- **→ FZX** / **→ Fixed** — конвертация шрифта между фиксированным и пропорциональным FZX-форматом. Fixed→FZX вычисляет визуальные границы каждого глифа, устанавливает ширину по фактическому содержимому и выравнивает растр влево. FZX→Fixed обрезает до 8×8 с учётом сдвига.

### Сдвиг (с переносом)

Кнопки-стрелки сдвигают пиксели глифа с переносом (вытесненные пиксели появляются с противоположной стороны).

### Трансформации

Выпадающий список содержит 22 операции, применяемых к выбранному глифу или ко всему шрифту:

| Группа | Трансформации |
|--------|--------------|
| Жирный | Bold Right, Bold Left, Bold Down |
| Курсив | Italic 1/2/3 Right, Italic 1/2/3 Left |
| Сдвиг (заполнение нулями) | Shift Right, Left, Up, Down |
| Отражение / Поворот | Flip Horizontal, Flip Vertical, Rotate 90° CW, 90° CCW, 180° |
| Выравнивание | Align Left, Align Right, Align Top, Align Bottom |

Выравнивание сдвигает пиксели глифа, пока крайний непустой столбец/строка не коснётся соответствующего края. Работает для фиксированных и FZX-глифов.

### Режим ширины

Выбор количества активных бит в строке глифа:

| Режим | Активные биты | Ширина в пикселях |
|-------|--------------|-------------------|
| 8 (full) | Биты 7–0 | 8 |
| 6 (left) | Биты 7–2 | 6 |
| 6 (right) | Биты 5–0 | 6 |
| 4 (left) | Биты 7–4 | 4 |
| 4 (right) | Биты 3–0 | 4 |
| Variable | Первый байт = ширина | 1–8 |

Неактивные столбцы затемняются как в сетке, так и в редакторе пикселей. При переключении с 4 (right) или 6 (right) в режим Variable байты ширины устанавливаются в соответствующее значение (4 или 6). Флажок **Hide W** управляет видимостью байта ширины (строка 0) в режиме Variable.

### Привязка символов

- Поле **Characters** + кнопка **Map** — привязать строку символов, начиная с выбранного глифа
- **Clear** — удалить привязку для текущего режима ширины
- **From (Cyr) / To (Lat)** — переназначение символов (например, кириллица на латинские аналоги)

### Экспорт/импорт метрик

- **Export .metrics** — сохранить привязки, режим ширины, ремап и метаданные шрифта в JSON
- **Import .metrics** — загрузить ранее экспортированный файл `.metrics`

### Текстовый образец (Text Sample)

Живой предпросмотр шрифта, отображающий три панграммы. Текст переносится посимвольно, заполняя доступную ширину панели, и перестраивается при изменении размера окна. Каждое предложение остаётся на своей строке (с переносом внутри).

- **Zoom** — масштаб пикселей 1×, 2× или 3×
- **Grid** — показывать промежутки между пикселями глифов (при масштабе > 1×)
- **Uppercase** — отображать весь текст заглавными буквами
- **Timex** — отображение с соотношением сторон пикселя 2:1 (пиксели половинной ширины), имитирующее режим Timex hi-res 512×192

### Копирование / Вставка глифов

- **Ctrl+C** — копировать выбранный глиф в буфер обмена
- **Ctrl+V** — вставить глиф поверх выбранного
- Работает внутри одного режима и между fixed/FZX режимами. Кросс-форматная вставка автоматически конвертирует: fixed→FZX подбирает ширину и раскладку, FZX→fixed обрезает до 8×8.

### Отмена / Повтор

Редактор шрифтов поддерживает до 50 уровней отмены. Отменяемы все модификации: редактирование пикселей, трансформации, инверсия, очистка, изменение количества глифов, ширины, а также все свойства FZX (высота, трекинг, ширина глифа, сдвиг, кернинг).

- **Ctrl+Z** — отмена
- **Ctrl+Y** или **Ctrl+Shift+Z** — повтор
- Загрузка нового файла шрифта или создание нового шрифта очищает историю отмен
- Отмена работает при переключении между режимами (фиксированный ↔ FZX)

### Пропорциональные шрифты FZX

FZX — формат пропорциональных шрифтов ZX Spectrum с переменной шириной глифов (1–16 пикс.), настраиваемой высотой (1–16 пикс.), сдвигом и кернингом для каждого глифа, а также знаковым трекингом. В режиме FZX:

- Управление для каждого глифа: **Width**, **Shift**, **Kern**
- Управление для всего шрифта: **Height**, **Tracking**
- Сетка глифов использует гибкую раскладку, отражающую реальную ширину
- Все трансформации адаптированы для растровых изображений переменной ширины

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Ctrl+Z | Отмена |
| Ctrl+Y / Ctrl+Shift+Z | Повтор |
| Ctrl+C | Копировать глиф |
| Ctrl+V | Вставить глиф |
| Стрелки | Навигация по глифам в сетке |
| P | Инструмент «Пиксель» |
| L | Инструмент «Линия» |
| R | Инструмент «Прямоугольник» |
| O | Инструмент «Круг / Эллипс» |
| E | Инструмент «Ластик» |
| B | Жирный вправо |
| I | Инвертировать глиф / шрифт |
| Delete | Очистить глиф / шрифт |

### Визуальный выбор формата

При загрузке файла шрифта размером 2048 байт появляется модальное окно с превью обоих вариантов интерпретации (обычный и чересстрочный) — по 16 глифов в строке × 4 строки. Щёлкните по нужному варианту для загрузки.

### Поддерживаемые форматы шрифтов

| Размер | Глифов | Формат |
|--------|--------|--------|
| 768 байт | 96 | Стандартный шрифт ZX Spectrum (ASCII 32–127) |

## 25. ZGS-редактор

ZGS-редактор — отдельная страница (`zgs_editor.html`) для редактирования векторных сцен ZGS (ZX Graphics Script), используемых в приключенческих играх для ZX Spectrum. ZGS использует байткод-формат с логической сеткой координат 128x96, отображаемой на экране 256x192 пикселей. Открывается по ссылке **ZGS Editor** во вкладке Tools, или напрямую через `zgs_editor.html`.

### Форматы файлов

| Расширение | Тип | Описание |
|------------|-----|----------|
| .zgs | Бинарный | Байткод ZGS с 10-байтным заголовком (магическое число `ZG`, версия, флаги, библиотека ассетов, смещение сцены), опциональное LZ-сжатие, библиотека ассетов (спрайты и скрипты фигур) |
| .zgt | Текстовый | Человекочитаемое ассемблероподобное представление байткода ZGS |
| .zgp | Проект | Файл многосценного проекта (JSON, v1/v2). Содержит имена и исходный текст всех сцен, индекс активной сцены, а также референсные изображения с настройками отображения для каждой сцены (v2) |

### Элементы управления в заголовке

- **Open** — загрузить файл `.zgs` (бинарный), `.zgt` (текстовый) или `.zgp` (проект)
- **New** — добавить новую пустую сцену, если проект содержит изменённые данные; сбросить проект, если все сцены пустые/стандартные
- **Save** — выпадающее меню с выбором формата:
  - **Save .zgs** — ассемблировать и сохранить активную сцену как бинарный файл `.zgs`
  - **Save .zgt** — сохранить активную сцену как текстовый файл `.zgt`
  - **Save .zgp** — сохранить многосценный проект как файл `.zgp`
  - **Save .asm** — экспорт всех сцен как полного Z80 ассемблерного файла для sjasmplus. Скачивается `.zip` с файлом `.asm`, скомпилированными `.zgs` бинарниками для каждой сцены, словарём упакованного текста (`.zdict`) и бинарными шрифтами (`font_8x8.bin`, `font_6x8.bin`, `font_4x8.bin`). Экспортированный файл содержит конфигурационный блок с 4 точками входа JP и флаги условной компиляции (см. ниже)
- **☾/☀** — переключение светлой/тёмной темы (синхронизируется с основным SpectraLab через `localStorage`)

### Вкладки сцен

Панель вкладок под заголовком показывает все сцены проекта. Нажмите на вкладку для переключения сцены. Каждая сцена имеет свой исходный текст, историю отмены/повтора и скомпилированный бинарник.

- Кнопка **+** — добавить новую сцену
- **Двойной клик** по имени вкладки — переименовать сцену
- Кнопка **×** на вкладке — удалить сцену (минимум 1 должна остаться)

### Конфигурационный блок ASM

Экспортированный `.asm` файл размещает конфигурационный блок с фиксированными адресами, начиная с ORG (по умолчанию 0x8000):

| Смещение | Содержимое | Описание |
|----------|------------|----------|
| +0x00 | `jp show_from_addr` | Очистить экран, нарисовать сцену по `scene_addr`, ждать клавишу |
| +0x03 | `jp show_by_num` | Очистить экран, нарисовать сцену `scene_num` из таблицы, ждать клавишу |
| +0x06 | `jp zgs_clear_screen` | Очистить экран используя атрибут `clear_color` |
| +0x09 | `jp zgs_wait_key` | Ожидание нажатия клавиши |
| +0x0C | `zgs_font_addr dw` | Адрес шрифта 8×8 для 32-кол режима (`font_8x8`, incbin) |
| +0x0E | `zgs_scene_addr dw` | Адрес сцены для `show_from_addr` (изменяемый) |
| +0x10 | `zgs_dict_addr dw` | Адрес словаря упакованного текста (или 0) |
| +0x12 | `scene_num db` | Индекс сцены для `show_by_num` (с 0, изменяемый) |
| +0x13 | `clear_color db` | Байт атрибута для `zgs_clear_screen` (0 = чёрный) |
| +0x14 | `zgs_font_42_addr dw` | Адрес шрифта 6×8 для 42-кол режима (`font_6x8`, incbin) |
| +0x16 | `zgs_font_64_addr dw` | Адрес шрифта 4×8 для 64-кол режима (`font_4x8`, incbin) |
| +0x18 | `scene_count db` | Общее количество сцен |
| +0x19 | `scene_table dw×N` | Адреса каждой сцены |

Для показа конкретной сцены программно: запишите индекс сцены в `scene_num` (ORG+0x12), затем `CALL ORG+3`. Для изменения цвета очистки экрана: запишите байт атрибута в `clear_color` (ORG+0x13).

### Условная компиляция (экспорт ASM)

Экспортированный `.asm` файл содержит восемь флагов `DEFINE` в начале, управляющих компиляцией групп опкодов. Закомментируйте неиспользуемые DEFINE для уменьшения размера бинарника — отключённые функции компилируются в минимальные заглушки `or 1 : ret`, а их подпрограммы, таблицы данных и переменные полностью исключаются.

| DEFINE | Опкоды | ~Байт | Описание |
|--------|--------|------:|----------|
| `ZGS_USE_LINES` | 0x64–0x6A | 443 | Рисование линий, горизонтальных и вертикальных линий |
| `ZGS_USE_RECTS` | 0x6B–0x70, 0x7E | 636 | Контур/заливка прямоугольника, очистка области |
| `ZGS_USE_CIRCLES` | 0x73–0x76 | 612 | Контур/заливка окружности |
| `ZGS_USE_ELLIPSES` | 0x89–0x8C | 800 | Контур/заливка эллипса |
| `ZGS_USE_POLYGONS` | 0x71–0x72 | 666 | Контур/заливка многоугольника |
| `ZGS_USE_FLOOD` | 0x19, 0x77 | 2300 | Заливка (включая 512-байт стек + 768-байт битовая карта посещений) |
| `ZGS_USE_TEXT` | 0x80–0x81 | 180 | set_cursor, print_text |
| `ZGS_USE_PACKED_TEXT` | 0x82 | 724 | print_packed (включая ~520 байт словаря) |
| `ZGS_USE_TEXT_42` | 0x83–0x85 | 968 | set_cursor_42, print_text_42, print_packed_42 (42 колонки, 6 пикселей; включая 768 байт font_6x8.bin) |
| `ZGS_USE_TEXT_64` | 0x86–0x88 | 968 | set_cursor_64, print_text_64, print_packed_64 (64 колонки, 4 пикселя; включая 768 байт font_4x8.bin) |
| `ZGS_USE_STAMPS` | 0x78–0x79 | 146 | Штамп (блит спрайта) |

`ZGS_USE_TEXT`, `ZGS_USE_TEXT_42`, `ZGS_USE_TEXT_64` и `ZGS_USE_ELLIPSES` определяются автоматически по содержимому сцен. Остальные DEFINE активны по умолчанию. Бинарные шрифты включаются условно: `font_8x8.bin` (32-кол) требует `ZGS_USE_TEXT`, `font_6x8.bin` (42-кол) — `ZGS_USE_TEXT_42`, `font_4x8.bin` (64-кол) — `ZGS_USE_TEXT_64`. Пользователь может заменить любой бинарный шрифт собственным дизайном. Когда все графические функции отключены (остаются только текстовые), система координат — обработчики точек/перемещений, `plot_pixel`, математические хелперы (`read_abs`, `read_dshort`, `read_dmed`) и таблицы паттернов/масок — автоматически исключается через внутренний флаг `ZGS_HAS_DRAWING`.

Зависимости: `ZGS_USE_PACKED_TEXT` требует `ZGS_USE_TEXT` (использует `print_one_char`). `ZGS_USE_RECTS` (контур) и `ZGS_USE_POLYGONS` (контур) требуют `ZGS_USE_LINES` (используют `draw_line`). Пользователь должен убедиться, что отключённые опкоды не встречаются в данных сцены.

### Текстовый редактор (левая панель)

Моноширинная текстовая область для редактирования ассемблера `.zgt`. Поддержка клавиши Tab для отступов. Автоматический рендеринг через 500 мс после окончания ввода.

**Категории инструкций:**

| Категория | Примеры |
|-----------|---------|
| Атрибуты | `set_ink white bright`, `set_paper blue`, `set_attr 0x47`, `set_pattern checker`, `set_mode xor`/`set_mode set` |
| Перемещение | `move_abs 10, 20`, `move_short 2, -1`, `move_dmed -5, 3` |
| Рисование | `dot_abs`, `line_dmed`, `hline_chain`, `vline_abs`, `rect_fill_abs`, `circle_outline_abs`, `polygon_fill`, `flood_abs` |
| Пакетные | `dot_batch`, `line_batch`, `rect_fill_batch` |
| Ассеты | `.sub`/`.endsub` (скрипты фигур), `.sprite`/`.endsprite` (растровые спрайты), `call`, `stamp_abs`, `stamp_chain` |
| Текст | `set_cursor col, row`, `print_text "строка"`, `print_packed "строка"`, `set_cursor_42 col, row`, `print_text_42 "строка"`, `print_packed_42 "строка"`, `set_cursor_64 col, row`, `print_text_64 "строка"`, `print_packed_64 "строка"` |
| Управление | `.repeat`/`.endrepeat`, `wait_key`, `clear_region`, `end` |

### Предпросмотр (правая панель)

Холст 256x192 (CSS-масштабирование 2x с пиксельной интерполяцией), отображающий отрендеренную сцену.

- **Render** — принудительный рендеринг сцены
- **Play** — пошаговая анимация рисования (один опкод за тик)
- **Step** — выполнить один опкод

- **Pen** — переключить отображение перекрестия пера
- **Grid** — переключить сетку знакомест 8×8 с разделителями третей экрана

Отображает ошибки ассемблера с номерами строк или информацию об успехе (размер файла в байтах, количество опкодов).

### Референсное изображение (сворачиваемый блок)

Загрузка внешнего изображения в качестве образца для рисования, отображаемого поверх холста предпросмотра. Каждая сцена хранит своё референсное изображение и настройки. Заголовок секции переключает открытие/закрытие (состояние сохраняется в localStorage).

- **Load** — выбрать файл изображения (любой формат, поддерживаемый браузером)
- **Clear** — удалить референсное изображение из активной сцены
- **Show** — переключить видимость без удаления изображения
- **Opacity** — ползунок прозрачности (5%–80%, по умолчанию 30%)
- **X / Y** — смещение позиции в пикселях (по умолчанию 0, 0)
- **W / H** — размер отображения в пикселях ("auto" = 256×192, соответствует экрану ZGS)

При добавлении новой сцены референсное изображение и настройки текущей сцены копируются в новую. Референсные изображения сохраняются в файлах проекта `.zgp` (формат v2), с дедупликацией между сценами для экономии размера. Файлы `.zgp` версии 1 загружаются нормально (сцены без референса).

### Панель текста

При выборе инструмента **Text** появляется панель с элементами:

- **Информация о курсоре** — показывает текущую позицию курсора после клика по холсту
- **Режим текста** — выпадающий список для выбора ширины символа: **32 col** (8 пикселей, стандарт), **42 col** (6 пикселей), **64 col** (4 пикселя). Каждый режим использует независимое отслеживание курсора и адрес шрифта
- **Поле ввода текста** — введите текст для печати
- **Кнопка Print** — вставляет `print_text "..."`, `print_text_42 "..."` или `print_text_64 "..."` в зависимости от выбранного режима текста

Сначала кликните по холсту для установки команды `set_cursor` (вариант зависит от режима: `set_cursor col, row`, `set_cursor_42 col, row` или `set_cursor_64 col, row`), затем введите текст и нажмите Print для вставки соответствующей команды печати. Две операции разделены, что позволяет рисовать между размещением курсора и вводом текста.

Текст рендерится шрифтом ROM ZX Spectrum (8×8 для 32-колоночного, 6×8 для 42-колоночного, 4×8 для 64-колоночного, символы 32–127) с текущим атрибутом. Курсор продвигается после каждого символа и переносится на следующую строку по достижении предела колонок (32, 42 или 64). Шрифт 6×8 использует столбцы 0-5 из 8×8 ROM-шрифта. Шрифт 4×8 получен операцией OR над парами столбцов из 8×8 шрифта (выходной_бит[n] = входной_бит[2n] | входной_бит[2n+1]).

#### Упакованный текст (`print_packed`)

`print_packed "строка"` работает визуально идентично `print_text`, но использует словарное сжатие для уменьшения размера байткода на 30–50% для английского текста. Кодер использует словарь распространённых биграмм, триграмм и слов. Используйте для длинных текстовых пассажей (описания в adventure-играх, диалоги). Директива `.dict` выбирает словарь кодирования:

- `.dict lower` — встроенный словарь английского строчного (по умолчанию)
- `.dict upper` — встроенный словарь английского заглавного
- `.dict user` — пользовательский словарь, загруженный из файла `.zdict`

Для использования пользовательского словаря выберите «Dict: user» в выпадающем списке на панели текста и нажмите «Load .zdict» для загрузки файла словаря. Пользовательские словари можно генерировать утилитой `zgs_mkdict.py` из текстовых файлов игры. Словарь блокируется после вставки первой команды `print_packed`, чтобы избежать рассогласования кодирования.

| Элемент | Вставляет |

При использовании **Step** в текстовом редакторе подсвечивается строка, соответствующая текущему счётчику программы VM. Работает на основе карты исходного кода, формируемой при ассемблировании.

| Tab | Вставить два пробела |
| Escape | Отменить активную полилинию |
| Alt+Стрелки | Сдвиг выделенных строк — смещение абсолютных координат на ±1 (сначала выделите строки) |
| Ctrl (при перетаскивании) | Ограничить фигуру соотношением 1:1 (квадрат/круг) |
| Alt (при перетаскивании) | Рисовать фигуру от центра вместо угла |

> **Примечание:** Горячие клавиши работают с любой раскладкой клавиатуры (русская, немецкая и т.д.) — они привязаны к физическому положению клавиш.
