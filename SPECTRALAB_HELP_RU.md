# SpectraLab — Справочник по интерфейсу

## 1. Введение

**SpectraLab** — это веб-редактор и просмотрщик графики ZX Spectrum. Поддерживает множество графических форматов ZX Spectrum для просмотра, редактирования, конвертации и импорта внешних изображений с продвинутыми алгоритмами дизеринга.

- **Версия:** 1.52.0
- **Лицензия:** MIT
- **Браузер:** любой современный (Chrome, Firefox, Edge, Safari)
- **Установка не требуется** — работает полностью в браузере

![Главное окно приложения](screenshots/main_window.png)

## 2. Компоновка интерфейса

SpectraLab использует двухпанельную компоновку:

- **Левая боковая панель** (225px) — все элементы управления, разделённые по вкладкам
- **Основная область холста** — отображение и редактирование изображения

Дополнительные плавающие панели появляются по мере необходимости:

- **Preview** — миниатюрный предпросмотр (в правом нижнем углу)
- **Sprite Editor** — плавающий пиксельный редактор спрайтов
- **Memory Viewer** — просмотр памяти снапшотов как 1-битная графика
- **Floating Palette** — палитра инструментов/цветов в полноэкранном режиме (клавиша Tab)

### Панель вкладок картинок

При открытии нескольких картинок над холстом появляется панель вкладок. Каждая вкладка показывает имя файла. Точка-индикатор отмечает изменённые (несохранённые) картинки. Нажмите на вкладку для переключения; нажмите кнопку закрытия (×) для закрытия картинки.

## 3. Файловые операции

### Открытие файла

Нажмите на поле выбора файла вверху боковой панели или **перетащите файл** на холст.

**Поддерживаемые форматы:**
`.scr`, `.53c`, `.atr`, `.bsc`, `.bmc4`, `.ifl`, `.mlt`, `.mc`, `.3`, `.img`, `.specscii`, `.sca`, `.btile`, `.wtile`, `.slp`, `.slw`, `.sna`, `.z80`, `.zip`, `.png`, `.gif`, `.jpg`, `.jpeg`, `.webp`, `.bmp`

### Новая картинка

Нажмите кнопку **New** для открытия диалога создания. Выберите формат:

| Формат | Расширение | Описание |
|--------|------------|----------|
| Screen | .scr | 256×192, битмап + атрибуты |
| ULA+ | .scr | 256×192, палитра 64 цвета |
| IFL | .ifl | 256×192, мультиколор 8×2 |
| MLT | .mlt | 256×192, мультиколор 8×1 |
| Border Screen | .bsc | 384×304, битмап + атрибуты + бордюр |
| BMC4 | .bmc4 | 384×304, мультиколор 8×4 + бордюр |
| RGB3 | .3 | 256×192, триколор RGB (8 цветов) |
| Gigascreen | .img | 256×192, двухкадровое смешение |
| Monochrome | .scr | 256×192, только битмап |
| Monochrome 2/3 | .scr | 256×128, только битмап |
| Monochrome 1/3 | .scr | 256×64, только битмап |
| Attributes | .atr | 32×24 цветовые ячейки |
| SPECSCII | .specscii | 32×24 текстовый режим |

### Сохранение

Нажмите кнопку **Save** или **Ctrl+S**. Файл сохраняется в исходном формате и скачивается браузером.

### ZIP-архивы

При открытии `.zip`-файла появляется модальный диалог со списком файлов в архиве. Нажмите на файл для извлечения и открытия.

## 5. Вкладка View

Вкладка View управляет отображением изображения.

### Масштаб (Zoom)

Выберите масштаб из выпадающего списка: **x1, x2, x3, x4, x5, x6, x8, x10, x20**. Также можно использовать **Ctrl+колесо мыши** или клавиши **1-5** для быстрого масштабирования.

### View Settings (раскрываемая секция)

Нажмите заголовок «View Settings» для раскрытия/сворачивания.

#### Border (бордюр)
- **Цвет:** Black, Blue, Red, Magenta, Green, Cyan, Yellow, White
- **Размер:** None, Small (16px), Medium (32px)

#### Palette (палитра)
Выберите палитру отображения из выпадающего списка.

#### Переключатели
- **Flash** — вкл./выкл. анимации мерцания (также клавиша **F**)
- **Attrs** — показать/скрыть наложение атрибутов. При выключенных атрибутах bitmap отображается как чёрный ink на белом paper (биты 1 = чёрный, биты 0 = белый)
- **Preview** — показать/скрыть панель предпросмотра (также клавиша **~**)

#### Paper grid (сетка)
- **Основная сетка:** None, 8px, 16px, 24px, 32px
- **Подсетка:** None, 1px, 2px, 4px, 8px, 16px

#### Border grid (сетка бордюра)
- **Сетка бордюра:** None, 8px, 16px, 24px, 32px
- **Подсетка бордюра:** None, 1px, 2px, 4px, 8px, 16px

### Элементы управления для конкретных форматов

#### Выбор паттерна 53c
Для форматов `.53c` / `.atr`: выбор паттерна заливки — **Checker**, **Stripes** или **Pattern** (DD/77).

#### RGB3
Для формата `.3` (триколор): переключатель **Emulate flicker** для имитации отображения на реальном оборудовании.

#### Gigascreen
Для формата `.img` (Gigascreen), выбор режима отображения:
- **Average** — смешанный вид обоих кадров
- **Flicker** — чередование кадров

#### Font (шрифт)
Для формата SPECSCII: нажмите **Browse** для загрузки файла шрифта (`.bin`, `.SpecCHR`). По умолчанию используется ROM-шрифт ZX Spectrum.

### Reference Image — справочное изображение (раскрываемая секция)

Загрузка внешнего изображения в качестве образца для рисования за холстом.

- **Load** — выбрать файл изображения
- **Clear** — удалить справочное изображение
- **Show** — переключить видимость
- **Opacity** — прозрачность (5%–80%)
- **X / Y** — смещение позиции (может быть отрицательным)
- **W / H** — пользовательские размеры (пусто = автоподгонка)

Справочные изображения сохраняются в файлах рабочего пространства.

### File Info — информация о файле (раскрываемая секция)

Отображает информацию о загруженном файле:
- **Name** — имя файла
- **Size** — размер файла в байтах
- **Format** — определённый формат
- **Dimensions** — размеры в пикселях
- **Frames** — количество кадров (для SCA-анимаций)
- **Type** — тип данных (для SCA)
- **Delay** — задержка кадра (для SCA)

### Справка

Внизу вкладки View нажмите кнопку **?** для открытия диалога справки с горячими клавишами и информацией о форматах.

## 7. Вкладка Edit — Цвет и палитра

### Стандартная палитра

Палитра показывает 8 цветов ZX Spectrum (0-7). Нажмите для выбора ink (помечается **I**), правый клик для выбора paper (помечается **P**).

Под палитрой:
- **Bright (B)** — переключение атрибута яркости
- **Flash (F)** — переключение атрибута мерцания
- Клавиша **X** — поменять ink и paper местами

### Палитра ULA+

Отображается при редактировании картинок формата ULA+. 64 цвета в 4 CLUT (Color Look-Up Table), по 16 цветов в каждом.

- **Grid** режим — все 64 цвета в сетке 8×8
- **Classic** режим — одна CLUT с кнопками выбора (0, 1, 2, 3)
  - CLUT 0: FLASH=0 BRIGHT=0
  - CLUT 1: FLASH=0 BRIGHT=1
  - CLUT 2: FLASH=1 BRIGHT=0
  - CLUT 3: FLASH=1 BRIGHT=1
- **Переключатель** — смена между Grid и Classic режимами
- **Сохранение палитры** — экспорт 64-байтного `.pal`-файла (кодировка GRB332)
- **Загрузка палитры** — импорт `.pal`-файла
- **Ctrl+клик** на цвете — открытие редактора цвета (R/G/B слайдеры, формат GRB332: 3 бита зелёного, 3 бита красного, 2 бита синего)

Ink и paper должны быть из одного CLUT.

### Палитра Gigascreen

Отображается для формата Gigascreen. Сетка из 16 столбцов показывает все виртуальные цвета, создаваемые чередованием двух кадров.

- Левый клик = выбор ink
- Правый клик = выбор paper
- Секция **Cell Colors** показывает 4 доступных цвета для текущей ячейки
  - **L** = цвет левой кнопки мыши
  - **R** = цвет правой кнопки мыши

## 8. Вкладка Edit — Кисти

### Форма кисти

Шесть форм кисти:

| Форма | Иконка | Описание |
|-------|--------|----------|
| Square | ■ | Квадратная кисть |
| Round | ● | Круглая кисть |
| HLine | — | Горизонтальная линия |
| VLine | \| | Вертикальная линия |
| Stroke | / | Прямой диагональный штрих |
| BStroke | \\ | Обратный диагональный штрих |

### Размер кисти

Выберите размер от 1 до 16 пикселей в выпадающем списке или используйте клавиши **[ ]** для уменьшения/увеличения.

### Предпросмотр кисти

Нажмите **` (обратный апостроф)** для переключения режима предпросмотра кисти — полупрозрачная кисть отображается у курсора.

### Custom Brushes — пользовательские кисти (раскрываемая секция)

12 слотов, расположенных в два ряда по 6. Каждый слот — холст 64×64 пикселя.

| Действие | Эффект |
|----------|--------|
| Клик на слоте | Выбрать кисть (пустой слот начинает захват) |
| Shift+клик на слоте | Захватить кисть с экрана |
| Ctrl+клик на слоте | Очистить слот |

Кнопки **↻ ↔ ↕** во вкладке Xform трансформируют буфер обмена при вставке, в остальных случаях — выбранную пользовательскую кисть.

#### Вкладки кистей

Пользовательские кисти поддерживают вкладки:
- **Custom brushes** — 12 свободных слотов
- **Tileset** — загруженные из `.768`/`.bin` файлов шрифтов/тайлсетов

Используйте кнопки **Save** и **Load** для сохранения/загрузки наборов кистей (формат `.slb`) или тайлсетов (`.768`/`.bin`).

### Barcodes — штрихкоды (паттерны бордюра)

Доступно для форматов BSC/BMC4. 8 слотов для полосовых паттернов бордюра.

| Действие | Эффект |
|----------|--------|
| Shift+клик на слоте | Начать захват, затем кликнуть на бордюре |
| Клик на слоте | Выбрать/отменить выбор |
| Ctrl+клик на слоте | Очистить слот |

Ширина определяется автоматически (8/16/24px). Выбранные штрихкоды ставятся кликом/перетаскиванием на бордюре.

Сохранение/загрузка наборов штрихкодов кнопками **Save/Load** (формат `.slbc`).

## 9. Вкладка Edit — Режимы рисования

Выпадающий список **Mode** управляет способом нанесения пикселей:

| Режим | Описание |
|-------|----------|
| Set | Рисование ink или paper в зависимости от кнопки мыши |
| Invert | Переключение пикселей (ink ↔ paper) |
| Replace | Перезапись всех пикселей под кистью |
| Recolor | Изменение только атрибутов, сохранение битмапа |
| Retouch | Изменение только битмапа, сохранение атрибутов |
| Masked | Тайловая маска из пользовательской кисти (фиксированное начало) |
| Mask+ | Тайловая маска из пользовательской кисти (начало от штриха) |

**Режимы Masked:** выберите пользовательскую кисть как паттерн/трафарет, затем выберите любую форму/размер кисти для рисования. В режиме Masked паттерн привязан к началу координат холста; в режиме Mask+ начало паттерна следует за началом штриха.

### Режим привязки (Snap)

Выпадающий список **Snap** управляет привязкой курсора:

| Режим | Описание |
|-------|----------|
| Grid | Привязка к размеру сетки (из вкладки View) |
| Grid× | Привязка к сетке, выравнивание по углу |
| Sub | Привязка к размеру подсетки |
| Sub× | Привязка к подсетке, выравнивание по углу |
| Zero | Привязка к сетке размером с буфер обмена от начала координат |
| Brush | Привязка к сетке размером с буфер обмена от первой вставки |
| Off | Пиксельная точность |

## 10. Вкладка Edit — Инструмент Text

При выборе инструмента Text (T) появляется секция:

- **Поле ввода текста** — введите текст для размещения

- **Размер шрифта** — 8, 12, 16, 20, 24 или 32 пикселя
- Кнопка **.768** — загрузить 8×8 битмапный шрифт ZX Spectrum (`.768`, `.ch8`, `.bin`)
- Кнопка **TTF** — загрузить шрифт TrueType/OpenType (`.ttf`, `.otf`, `.woff`, `.woff2`)
- Кликните на холсте для размещения текста

## 11. Вкладка Edit — Инструмент Airbrush

При выборе инструмента Airbrush (G) появляются дополнительные элементы:

- **Radius** — радиус распыления: 4, 8, 12, 16, 24 или 32 пикселя

При выборе инструмента Gradient (D) появляются дополнительные элементы:

## 13. Вкладка Edit — Слои (Layers)

Секция Layers (раскрываемая) позволяет многослойное редактирование:

- **Add** (+) — добавить новый слой (при первом использовании создаёт фоновый + новый слой)
- **Remove** (−) — удалить выбранный слой
- **Move Up** (↑) / **Move Down** (↓) — изменить порядок слоёв
- **Flatten** (⊟) — объединить все слои в один

Сохранение/загрузка проектов со слоями кнопками **Save/Load** (формат `.slp`).

## 14. Вкладка Edit — Редактор SPECSCII

Для картинок формата SPECSCII появляется палитра символов:

- **Сетка символов** — ROM-шрифт (0x20-0x7F) и блочная графика (0x80-0x8F)
- Клик на тайле для выбора символа для рисования
- **Предпросмотр символа** — увеличенное отображение выбранного символа с его кодом
- Правый клик на холсте для захвата символа + атрибутов с экрана

Доступные инструменты в режиме SPECSCII: Pixel, Line, Rectangle, Circle, Flood Fill, Eraser, Text.

Режимы рисования: Set (размещение символа), Invert (обмен ink/paper), Recolor (только атрибуты). Eraser очищает ячейку и удаляет её из текущего слоя.

SPECSCII поддерживает OVER-слои (XOR-композитинг), загружаемые из управляющих кодов потока. Экспорт SPECSCII в `.scr` через вкладку Transform.

## 15. Вкладка Transform (Xform)

### History (история)

- **Undo** (Ctrl+Z) — отмена действия (до 32 уровней)
- **Redo** (Ctrl+Y) — повтор отменённого действия
- **Clear** — очистка всего экрана

### Workspace (рабочее пространство)

- **Save Workspace** — сохранить все открытые картинки в `.slw`-файл
- **Load Workspace** — загрузить файл рабочего пространства (`.slw`)

### Конвертация формата

Выпадающий список **Convert to...** для конвертации текущей картинки в другой формат.

### Экспорт

- Выпадающий список формата экспорта
- Флажок **Embed** — встраивание данных
- Кнопка **Export** — экспорт в выбранный формат

### Generate

- **QR Code** — открыть диалог генератора QR-кодов

### Clipboard (буфер обмена)

| Кнопка | Клавиша | Описание |
|--------|---------|----------|
| Select | S | Выделение прямоугольной области |
| Cut | Ctrl+X | Вырезание (копирование + стирание) |
| Paste | Ctrl+V | Вставка содержимого буфера |
| Invert | N | Инвертирование (обмен ink ↔ paper) |
| Rotate | R | Поворот буфера/кисти на 90° по часовой |
| Flip H | H | Отражение буфера/кисти по горизонтали |
| Flip V | V | Отражение буфера/кисти по вертикали |

- Флажок **Snap to grid** — привязка позиции вставки к сетке
- При вставке кликните для размещения; клавиши R/H/V для трансформации

### Transform Selection

При активном выделении появляются кнопки:
- **↻ Rotate** — поворот выделения на 90° по часовой
- **↔ Mirror H** — зеркальное отражение по горизонтали
- **↕ Mirror V** — зеркальное отражение по вертикали

### Экспорт в ASM

- **Режим строк:** Line-based (полная строка в DEFB) или Block-based (8 байт в DEFB)
- **Направление:** Left to right, Right to left, Zigzag (start L-R), Zigzag (start R-L)
- **Visual comments (█·)** — визуальные комментарии из блочных символов
- **Save ASM file** / **Copy** — сохранить в файл или скопировать в буфер обмена

## 18. Image Import — импорт изображений

При загрузке файла PNG, GIF, JPG, WebP или BMP открывается диалог Image Import.

### Компоновка

Диалог показывает два холста:
- **ORIGINAL** — исходное изображение
- **PREVIEW** — результат дизеринга под ZX Spectrum

### Вкладка Image

#### Source (источник)

Обрезка исходного изображения:
- **X, Y, W, H** — прямоугольник обрезки
- **Reset** — сбросить к исходному размеру
- **Full** — использовать полное изображение
- **Detect** — автоопределение области 256×192
- **4:3** — зафиксировать соотношение сторон 4:3

#### Transform (преобразование)

- **Fit mode:**
  - Stretch — растянуть до заполнения (может исказить)
  - Letterbox — вписать в цель с полосами
  - Fill/crop — заполнить цель, обрезать лишнее
  - Fit width — подогнать по ширине
  - Fit height — подогнать по высоте

- **Align:** Top-Left, Top, Top-Right, Left, Center, Right, Bottom-Left, Bottom, Bottom-Right

- **Алгоритмы дизеринга:**

  Cell-Aware (с учётом атрибутов):
  - Cell Floyd, Cell Atkinson, Cell Serpentine, Cell Sierra 2, Cell Riemersma, Cell Ordered, Cell Blue Noise, Cell Pattern, Cell None

  Global (классические):
  - Floyd-Steinberg, Jarvis, Stucki, Burkes, Sierra, Sierra Lite, Sierra 2-Row, Serpentine, Riemersma, Atkinson, Ordered 4×4, Ordered 8×8, Blue Noise, Pattern, Noise, None

  По умолчанию дизеринг — **None** (ближайший цвет, без дизеринга).

- **Paper** — правило назначения цветов ink и paper в каждой ячейке:
  - **Auto** — по умолчанию; назначение определяется порядком индексов палитры
  - **Darker color** — более тёмный из двух цветов ячейки становится paper (для каждой ячейки отдельно, по перцептуальной яркости). Для одноцветных ячеек (ink и paper одинаковые) цвет сравнивается с серединой: тёмные цвета становятся paper (биты 0), светлые — ink (биты 1)
  - **Lighter color** — более светлый из двух цветов ячейки становится paper. Для одноцветных ячеек цвет сравнивается с серединой: светлые цвета становятся paper (биты 0), тёмные — ink (биты 1)
  - **First pixel paper** — цвет левого верхнего пикселя в каждой ячейке становится paper; полезно для спрайтшитов, где угловой пиксель рамки определяет цвет фона

- **LAB colors** — использовать цветовое пространство LAB для перцептуального сопоставления
- **Grayscale** — преобразовать в оттенки серого перед обработкой
- **Mono output** — вывод только чёрно-белый

#### Output (выход)

- **Format:** SCR, ULA+, 53c (attr), IFL (8×2), BMC4 (8×4), MLT (8×1), BSC, RGB3, Mono, Mono 2/3, Mono 1/3
- Выбор **Palette**
- **53c Pattern** (для формата 53c): Checker, Stripes, DD/77
- **ULA+ Palette:** Auto, Load .pal, From picture
- **Position:** X, Y смещение
- **Size:** W, H (с фиксацией соотношения сторон)

### Вкладка Adjustments (настройки)

| Параметр | Диапазон |
|----------|----------|
| Contrast | -100 — +100 |
| Brightness | -100 — +100 |
| Saturation | -100 — +100 |
| Gamma | 0.20 — 3.00 |
| Sharpness | 0 — 100 |
| Smoothing | 0 — 100 (билатеральный фильтр — снижение шума с сохранением краёв) |
| Levels | Black point (0-127), White point (128-255) |
| Color balance | Каналы R, G, B (-50 — +50 каждый) |

### Нижние элементы

- **Zoom:** x1, x2, x3
- **Grid** — показать сетку 8×8 на превью
- Кнопки **Cancel** / **Import**

#### Playback (воспроизведение)

Статистика:
- Original frames / Trimmed frames / Duplicates
- Original duration / Trimmed duration
- Original size / Trimmed size

#### Preview Mode
- **All frames** — воспроизведение всех кадров

- Кнопка **Play** — старт/стоп воспроизведения

## 20. Memory Viewer — просмотрщик памяти (плавающая панель)

  - **< Page / Page >** — перемещение на 1 страницу
- **Width** — ширина отображения в байтах (1-8)
- **Height** — высота отображения в строках (1-64)
- **Invert** — инвертировать отображение
- **Grid** — показать наложение сетки
- **Char mode** — знакоместо-выровненное отображение
- **Zoom** — x1, x2, x3, x4

### Preview (предпросмотр)

Миниатюрный предпросмотр выделенной области спрайта.

### Grab (захват)

Захват спрайтов из просмотрщика памяти в список спрайтов:
- Кнопка **Grab** — захватить отображаемый спрайт
- **Mode:** Single sprite, Sprite phases, Singles grid, Phases grid
- Настройки сетки: размер по ячейкам или количеству, столбцы/строки, порядок
